## 另一个文档面包屑（siyuan-another-doc-breadcrumb）

**中文** | [English](README.md)

> 在编辑器上方显示当前文档路径信息的[思源笔记](https://github.com/siyuan-note/siyuan)插件。

> **分叉声明**：本插件是 [OpaqueGlass/syplugin-fakeDocBreadcrumb](https://github.com/OpaqueGlass/syplugin-fakeDocBreadcrumb) 的分叉，采用 [AGPL-3.0](LICENSE) 许可证。版权归 OpaqueGlass 所有，修改部分版权归霞葉（kasuha）。

> 当前版本：v1.0.6
> - 分家自 syplugin-fakeDocBreadcrumb v1.5.1，更名另起炉灶；
> - 页签关闭走公开 API、菜单懒加载使用原生 loadSubmenu、批量请求合并降级、设置校验与迁移保留、样式迁移官方 pluginsStyle 机制；
> - 新增原生块面包屑左键跳转设置（默认关闭，右键行为保持不变）；同行模式复用思源原生箭头并移除重复的原生当前文档节点；
> - 插件箭头菜单无可显示层级时回退到思源原生面包屑菜单；
>
> 详见[更新日志](CHANGELOG.md)

### 快速开始

- 从 Release 解压 `package.zip`，将文件夹移动到 `工作空间/data/plugins/`，并将文件夹重命名为 `siyuan-another-doc-breadcrumb`;
- 开启插件即可；

### 功能说明

- 在编辑器顶部添加当前文档导航路径；
- 点击跳转到对应文档，右键点击展开该文档的下层文档；
- （设置项）启用“原生块面包屑左键跳转”后，SiYuan 原生块面包屑及其展开层级左键滚动跳转到对应位置，右键行为保持原有行为（默认关闭）；
- （设置项）“文档/标题箭头显示大纲菜单”开启时，原生文档与标题箭头使用仅含标题的大纲菜单。默认关闭，同行与两行模式均使用支持全部子块、分页与懒加载子菜单的导航，已保存的选择始终保留；
- 插件路径按钮支持 Enter / Space 激活、ArrowDown 打开下层文档菜单、ArrowLeft / ArrowRight 移动焦点（同行模式可跨越插件与原生项的边界）；
- （设置项）下层文档菜单支持继续按照层级展开，最多支持7层级；
- （设置项）层级超出5时，默认保留前2层级、后3层级；
- （设置项）在面包屑右侧显示上一篇下一篇按钮；
- （设置项）点击上一篇/下一篇时在当前位置打开（替换当前页签，默认关闭）；
- （设置项）在菜单中显示新建文档按钮；

### 兼容性说明

本插件：
- 要求思源 v3.8.0+；
- 不支持在移动端显示，请使用其他插件，如层级导航插件中的面包屑；
- 启用“与块面包屑在同一行显示”后，文档面包屑与块面包屑显示在同一行，超长时作为一条连续内容带整体横向滚动；未启用时仍显示在块面包屑上方（占用一行）；
- 文档面包屑与块面包屑之间复用思源原生的“>”箭头；插件当前文档项替代原生重复的首个文档节点并保留点击功能；如果主题将面包屑中文档间的分隔符显示为“/”，可能无法点击显示子文档选择菜单，需要在设置项中启用“覆盖主题面包屑分隔符“>”样式”；

插件依赖若干思源未在 API 文档中声明的内部结构（页签关闭链 `getAllTabs()` / `Tab.parent.removeTab`、大纲接口返回的 `blocks`/`children` 字段、加密笔记本 `closed` 字段语义），已对照思源 v3.8.6 源码验证；升级思源后若出现相邻导航/菜单异常，请反馈日志以定位。

## 与上游的差异

本插件与上游 `syplugin-fakeDocBreadcrumb`（v1.5.1，上游已进入维护阶段，停止功能新增）的主要差异：

- **重构**：改用 TypeScript 编写并开启 strict 类型检查；esbuild 单文件 bundle 构建；`dist/` 作为唯一插件目录；
- **默认值调整**：“与块面包屑在同一行显示”与“在菜单中显示新建文档按钮”默认开启（上游默认关闭）；“在面包屑所在分屏区打开文档”固定生效、不再提供开关（上游为默认开启的实验性开关）；
- **移除的设置项/功能**：
  - 自动修复聚焦错误（上游隐藏设置，修复已上线稳定运行半年，不再需要开关）；
  - 展开菜单时滚动到当前路径（上游隐藏设置）；
  - 允许悬停显示浮窗（上游该功能实现不完整）；
  - 文档重命名/移动后立即更新（本插件固定为总是即时更新，上游默认关闭需手动开启）；
  - 在更多情况下显示、输入时隐藏、交换左右键点击、设置页“上下滑动查看更多”提示项；
- **转正的功能**：在面包屑所在分屏区打开文档、下层文档菜单扩展层级（最多 7 层级）、菜单中新建文档按钮（默认开启）；
- **新增设置项**：原生块面包屑左键跳转（默认关闭，右键行为不变）；上一篇/下一篇按钮显示样式（文字/仅箭头）；上一篇/下一篇替换当前页签（默认关闭）；
- **稳定性与性能**：子菜单懒加载使用原生 `IMenu.loadSubmenu`，加载状态、定位与键盘焦点由思源处理（上游为每项一个 MutationObserver）；面包屑省略由逐个压缩改为二分查找，reflow 从 O(n) 降到 O(log n)；文档结构变更按 100ms 窗口合并刷新，批量移动不再产生请求洪峰；打开文档双事件去重；文档路径改批量 getDocsInfo 一次读盘；切页签/文档内聚焦复用已取得的模型，不再重复请求；结构变更按事件中的笔记本与路径只刷新受影响的编辑器、只失效对应缓存；路径先渲染，上一篇/下一篇异步补上；光标换块时按签名复用省略结果，减少强制重排；初始化失败自动重试（最多 5 次）并回退默认配置；请求层统一错误处理与空值兜底；
- **安全**：文档名、图标拼入菜单 HTML 前转义，封堵两处 XSS；
- **生命周期**：监听 destroy-protyle 完整清理，卸载无残留节点；设置保存按需重建；样式经思源官方 pluginsStyle 机制注入，卸载时官方自动移除；
- **其他**：同行模式复用思源原生箭头并移除重复的原生当前文档节点；移除对 OpaqueGlass 外部调试协议（`OpaqueGlassDebugV2`）的依赖；已对照思源 v3.8.6 源码验证并文档化三处未公开依赖（页签关闭链、大纲接口字段、加密笔记本 closed 语义）。
